FEM Truss Tutor

About this tool

The method

The tool solves 2D and 3D pin-jointed trusses with the direct stiffness method, one stage at a time:

  1. Define the nodes, bars, supports and loads, and number the DOFs.
  2. Compute each bar's length and direction cosines.
  3. Build each bar's stiffness matrix: [k] = [T]ᵀ[k′][T].
  4. Assemble all [k] into the global [K].
  5. Apply the supports: delete constrained rows and columns to get [Kff]{uf} = {Ff}.
  6. Solve by Gaussian elimination to get displacements.
  7. Recover reactions R = Ku − F, then strain, stress and force in each bar.

How to use it

  • Pick a preset in the sidebar. Edit E (GPa), A (mm²) and loads (kN); everything recomputes. Invalid values are rejected and the last valid one is kept.
  • Move between stages with the stepper, Previous/Next, or the ← → keys. The stage is in the URL (#stage-4).
  • In 3D, drag the diagram to rotate; use Reset view, Isometric, Front or Top.
  • Hover bars, table rows and matrix cells: related items highlight everywhere. In Stage 4, hover a cell of [K] to see where its value comes from.
  • Guided demo loads the textbook problem (Logan Ex. 3.9) with prompts for each stage. Print / export makes a printable solution of all stages.

Units

Calculations use SI base units (N, m, Pa). Displays use kN, mm, MPa, GPa and MN/m.

Limits

Straight pin-jointed bars only: no frames, bending, dynamics or nonlinear behaviour. Geometry and supports are fixed per preset. All math runs in your browser; nothing is sent anywhere.
